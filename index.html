🧩 Import real Hytale recipe assets

Paste a recipe JSON asset from a game build you trust. Only explicit item IDs and positive quantities are supported. Complex tags and resource types are rejected, never guessed. Review before saving.

📦 Bulk recipe import

Import a JSON array of recipe assets or an object containing a recipes array. Invalid or ambiguous recipes are skipped; preview before saving. Export your recipes first if you want a backup.
