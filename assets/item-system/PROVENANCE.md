# Original item visual system — Stage18

`categories.webp` is an original AI-assisted illustration atlas created for Hytale Craft on2026-11-16, using the available image generation tool. No game images, textures, models, external fan art or dataset icons were used as image inputs. It is not official Hytale art and does not establish any game's actual object design, material or rarity. Backgrounds/frames are independent UI components.

16 row-major equal square tiles: sword, axe, pickaxe, helmet, breastplate, timber, ordinary stone, generic silver metal ingot, woven fabric, herb, meal, potion, chair, bricks, workbench, neutral medallion.14 requested families plus workbench and neutral. These are **category illustrations** only. Ores, unusual weapons and unknown silhouettes are not silently mapped to ordinary stone/sword. The atlas is rendered as a clipped image grid without altering the generated content; WebP is a resolution/format optimization of the source PNG. Original source is retained in the private working image directory; the complete shipped atlas is sufficient for UI reproduction. SHA-256 and dimensions are in manifest.json.

LevelA uses7 existing original learning illustrations, mapped only to their exact lesson IDs. No real game item has an individually verified depiction in this stage. Such mappings require evidence of silhouette/material and independently approved image rights before being added. LevelB uses conservative category keywords/metadata. LevelC uses a neutral medallion with accessible 'image unavailable' wording and CSS fallback if the atlas itself fails. No game rarity is invented; source quality, when present, is a source claim rather than an image tint.

Visual grammar: square96px(default)/116px(detail)/64px(compact)/42px(material) slots, dark navy background, bronze metal edge, warm gold focus, restrained cyan illumination; opaque quantity labels, explicit availability text and meaningful focus/disabled states. Category labels are available to assistive technology and in details/tooltips. Native tooltips are supplemental, never the only disclosure.
