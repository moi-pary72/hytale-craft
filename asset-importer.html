Official asset recipe importer

Import recipe JSON files from your own legally obtained Hytale game assets. No invented recipes. Data stays in this browser.

1. Select JSON files

Supports Server/Item/Recipes/*.json and item files with an embedded Recipe property. Multiple files supported.

No files selected.

2. Review and import

Only recipes with a specific ItemId for every input and a single unambiguous output can be imported into the current planner. ResourceTypeId and ItemTag inputs, multiple outputs and duplicate recipe names are skipped rather than guessed.

Existing recipes are never overwritten. Importing stores only recipes in localStorage. Keep a backup using the planner's Export JSON button.
