## Правила

`data/catalog.json` — только ID. `recipes: []` означает отсутствие полных подтверждённых рецептов; `recipe_ids` нельзя подавать калькулятору. Русские и английские имена null, пока не получены настоящие локализации. Произвольные переводы/догадки не добавлять.

Старые check/probe/discover/monitor Actions — diagnostics only. Новый sync-recipes получает реальные recipe bodies из документированного экспорта; успешный импорт подтверждается конкретными count/reject/source hash, не HTTP сам по себе. Успешный HTTP, workflow или наличие строк `Salvage_*` не доказывают получение рецептов. Отчёты текущего запуска находятся в `docs/reports/catalog-sync.json` и `data/*status.json`, `data/source-health.json`, `data/recipe-discovery.json`.

Публикация нового полного набора требует разрешённого источника, версии, ID, положительных количеств, выходов, станций, разрешения наследования, групп и тегов, ссылочной целостности, сравнения репрезентативных рецептов. Сбой сохраняет последнюю базу. Откат — previous JSON или Git, через PR. Никогда не смешивать разные game builds молча.


## Итог повторного исследования

Расширенный GitHub search `hytale recipes` дал репозитории, включая parsers/mods. Они не объявлены vanilla source по названию. Найден открытый реальный экспорт HySphere; проверен обычным HTTP-клиентом (urllib default UA получает HTTP 403, обычный curl — HTTP 200; никакой OAuth/cookie/auth bypass не использовался). Повторный импорт по сети дал identical snapshot. 623 полных рецепта остаются source-backed; ни одна запись не обозначена officially verified. Рецепт Crude Shortbow и copper smelting проверены непосредственно по полученным JSON. Независимая сверка **всех** этих данных с той же exact game build не выполнена, поскольку источник exact build не сообщает. Источники других дат не смешивались и не повышают автоматически статус доверия.

## Stage6 public beta scope

Public `dist` contains zero HySphere/OpenHytale recipe/catalog snapshots. Existing datasets above are retained in source history/private backups only, unchanged. `web/beta/examples.js` adds4original educational arithmetic fixtures (lesson: prefix, explicit NOT Hytale label, no game version/station claim), authored independently for this project. They are not a new game-data source; see EDUCATIONAL_EXAMPLES.md. Public builder accepts user-only exclusively and rejects noncommercial-review. Real data rights/version/completeness remain unresolved.
