## Выход, альтернативы и разборка

- Для всех13IsaacGuru отображает один целевой предмет на крафт; Source output multiplier в выбранном разделе не раскрыт. Сравнение выхода поэтому **неполное**, а не «13совпадений».
- В8записях выборки есть видимые групповые/обобщённые материалы (Crude Sword/Pickaxe/Hatchet, Copper Sword/Pickaxe, Workbench, Campfire и Furnace). Нельзя заменить “any” первым подходящим предметом или объявить произвольное смешивание подтверждённым. Членство/units/mixed policy нужно получать из той же версии game files.
- На8страницах weapons/tools IsaacGuru отдельно показывает Salvaging; у двух слитков и трёх станций пишет невозможность salvage. Это не inverse craft: возвращаемые материалы/количества отличаются от затрат. Полное попарное сравнение salvage body Source↔Isaac не выполнено; ссылки “Used in” не приняты за полную recipe body.
- Source/Furnace дополнительно выводит ссылки на тот же целевой предмет перед основными материалами. Это наблюдение UI, **не доказанный self-consuming recipe/bug/цикл игровых данных**. Требуется исходный разрешённый JSON этой build. Не переносить эти ссылки в inputs автоматически.

## Третий источник: HYTL

Через штатный UI открыт [Crude Shortbow](https://hytl.dev/items/Weapon_Shortbow_Crude): target ID совпал, показанные материалы/количества совпали с двумя справочниками. HYTL показывает3bench entries/categories/Any tier, включая названия Workbench, Weapon Bench, Armory; Isaac отображает Workbench/Blacksmith's Anvil/Forge. Алиасы надо связывать по подтверждённому ID, не названию. HYTL показывает0s, Isaac1.5s — числовое расхождение времени; Source не показывает время в выбранном разделе. HYTL ItemLevel9 противIsaac13 — дополнительный сигнал разных версий/нормализации, не основание выбрать один сайт «правильным».

HYTL timeline теперь указывает release0.7.7/pre0.8.0-pre.5, но exact version выбранной записи не установлена. HySphere catalogue selected-item browser view в одном чтении оставался “Loading item”; повторное чтение не дало надёжно выделенной карточки. Поэтому он не добавлен фиктивным третьим полным совпадением и его запрещённый/api/ не использовался.
