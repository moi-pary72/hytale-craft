# Настоящий каталог на Android — личная лаборатория

Это локальная исследовательская версия, не опубликованный релиз. Основной сайт и main не изменяются. Данные: HySphere, документированные некоммерческие экспорты https://hysphere.app/data ; условия https://hysphere.app/about#data-license . Нет подтверждённых прав на публичную/коммерческую перепубликацию всей базы. Не загружайте каталог в облачный хостинг или публичные архивы.

## Запуск на телефоне

1. Установите бесплатный **Termux** из официального каталога F-Droid: https://f-droid.org/packages/com.termux/ . Android может попросить разрешить установку приложения из браузера. Это решение выполняет владелец телефона. Не используйте случайные APK-сайты.
2. Откройте Termux, вставьте команды ниже. Нужен интернет для установки Python, собственного кода и трёх открытых экспортов. Репозиторий загружается неглубокой копией текущей ветки, без старой истории.

```sh
pkg install -y python git
```

```sh
git clone --depth 1 --branch codex/stage19-real-item-visuals https://github.com/moi-pary72/hytale-craft.git "$HOME/hytale-craft-lab"
```

```sh
python "$HOME/hytale-craft-lab/scripts/android_real_lab.py" --download-open-export
```

3. Дождитесь сообщения **Verified: 3219 items**. В Chrome **на этом же телефоне** откройте **http://127.0.0.1:8765/**. Termux оставьте работающим; при необходимости переключитесь в браузер через список приложений. Это loopback самого телефона, не сервер в интернете. Другие устройства не получают доступ к базе.

При повторном запуске достаточно последней команды без `--download-open-export`. Если Android остановил Termux, выполните её снова. Не используйте одновременно второй экземпляр сервера. Ctrl+C в Termux завершает доступ. Не меняйте адрес на `localhost` и не очищайте данные Chrome: сохранение привязано к адресу/браузеру. Не удаляйте Termux до сохранения необходимых собственных данных.

Если каталог установки уже существует, не клонируйте поверх него и не удаляйте `.private`: запускайте сохранённый скрипт. В случае иной прежней версии сообщите её SHA — инструкция не выполняет автоматического обновления ветки или удаления данных.

Для одновременного изготовления используйте общий Plan. В Plan доступны сохранённые Projects, Advanced, Export workspace и Import workspace. Экспорт содержит только введённые пользователем данные; сохраняйте его из Chrome в собственные загрузки. Не является экспортом исходного каталога.

Beautiful/Compact сохраняется локально. Инвентарь, цели и проекты сохраняются при перезапуске сервера и отключении источника; удалённые/неизвестные ID не стираются. Публичный HTTPS-сайт и локальная лаборатория имеют разные хранилища: автоматической синхронизации с публичным сайтом нет. Частный viewer сейчас англоязычный; основной международный интерфейс не изменялся.

Это не подтверждает игровые станки, открытия или точную текущую версию игры. Экспорт датирован12августа2026; точный билд неизвестен. Неполные цепочки показываются честно. ## Данные и восстановление

Под каталогом установки:

- `.private/android/source/` — три **настоящих исходных экспорта**; не копия кода.
- `.private/android/backup/hysphere-pinned-private.zip` — локальная закрытая ZIP-копия этих данных. Все три записи перечитываются, CRC/SHA-256 проверяются. Манифест ожидаемых хешей — `docs/stage18/RESTORE_MANIFEST.json`.
- `.private/android/last-verification.json` — проверка исходников, нормализованного SHA и метрик, SHA локального ZIP.
- `.private/android/build-*/research-data.json` — локальный каталог с отдельным `meta.excluded` для1471записи; исходные строки остаются в recipes.json. Это не серверный публичный файл.

При отсутствии source и наличии локального ZIP скрипт автоматически восстанавливает данные **без сети**. Если перенос выполняется из другого разрешённого локального расположения, используйте `--restore /полный/путь/к/zip` при отсутствующей папке source. Уже существующие исходники/архивы не заменяются. Не используйте облачную загрузку ZIP без уточнения прав. Если изменился опубликованный экспорт, SHA-проверка остановит загрузку; программа не смешает версии и не обойдёт доступ.

Код и инструкции восстановимы из PR19. Проверенное восстановление **данных** выполнено из локального ZIP в пустой каталог; нормализованный SHA совпал. До фактической установки на телефон все дополнительные копии реальных данных остаются только в workspace. ZIP на одном телефоне защищает от потери рабочей папки, но **не от удаления Termux/утраты телефона**. Постоянная внешняя резервная копия всей базы пока не согласована; это ограничение не решается одной резервной копией кода.

## Почему нет приватной HTTPS-ссылки

Нет настроенного авторизованного частного HTTPS-хостинга/доступа к нему. Подключение новой платформы с полной копией базы также потребует прояснить разрешённый объём хранения/предоставления третьим лицам. Секретная общедоступная ссылка не является приватным доступом. Экспорты не предоставляют CORS для загрузки с произвольного внешнего сайта. Поэтому выбран локальный запуск напрямую на устройстве без копирования базы на чужой сервер и без обхода браузерных ограничений.

Физический Android недоступен для проверки: проверены Python-сценарий, реальное офлайн-восстановление и Chromium на ширинах320/360/393/430. Установка Termux и возможные ограничения энергосбережения конкретного телефона требуют личной проверки владельца. После запуска сайт работает без дальнейшего интернета, пока браузер/сервер остаются открыты; это не установленный offline PWA.
