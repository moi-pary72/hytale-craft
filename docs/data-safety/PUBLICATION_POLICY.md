# Publication policy and automation boundary

Confirmed source restrictions: HySphere's noncommercial-attribution wording is not a commercial republication grant; HytaleDB's compilation is NC. Uncertain: full OpenHytale data-compilation reuse; its code's MIT wording does not settle data rights. Individual IDs, source links, aggregate counts and original interface code are not automatically infringements. The audit distinguishes them from a copied catalogue.

Original `lesson:` exercises and synthetic `Fixture_` regression data are independently authored and labelled non-game; no recipe is presented as vanilla Hytale. Existing generated artwork and the approved interface are not changed. Source/provider permissions and underlying game rights remain separate.

The five third-party collection workflows in this branch have no schedules or write permissions; manual execution prints a pause notice only. Corresponding legacy CLI/network entry points fail before requests or snapshot writes. Main's existing automation is unchanged until an owner-approved merge; that residual risk is explicit. Existing read-only official-downloader/server-source diagnostics do not acquire game assets. Diagnostics with raw sample-capture capability are not retained as active entry points.

`audit_repository_data.py` guards the current tracked tree against known bulk snapshots, active legacy pointers, private review candidates and archives. It is a heuristic policy check, not a copyright detector or proof that every possible encoded fragment is absent. It does not inspect or erase history, other refs or server artifacts.

GitHub Pages deploy workflow is unchanged and only runs on main. This branch's commits use the Cloudflare-documented `[CF-Pages-Skip]` prefix to omit preview deployment while leaving GitHub validation enabled. Reference: https://developers.cloudflare.com/pages/configuration/git-integration/github-integration/#skipping-a-build-via-a-commit-message . No deployment configuration, production branch, artwork or public build policy is changed. Subsequent commits to this draft branch must retain that prefix; merges/deployments are NOT authorized by this task.
