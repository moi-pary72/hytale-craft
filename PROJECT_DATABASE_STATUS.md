# Hytale Craft — состояние базы рецептов (14.11.2026)

Репозиторий: https://github.com/moi-pary72/hytale-craft

## Подтверждено
- Сайт работает как статическая страница, калькулятор пока не содержит полной достоверной базы.
- Предыдущий discovery workflow завершался успешно, но это НЕ означает, что рецепты были загружены.
- Реальные рецепты находятся в Assets.zip по путям Server/Item/Recipes/**/*.json и в Recipe внутри Server/Item/Items/**/*.json.
- Добавлен scripts/import_game_assets.py — импортирует реальные рецепты из пользовательского Assets.zip, сохраняя ItemId, ResourceTypeId, ItemTag, количества и BenchRequirement.
- Не публиковать пустую или выдуманную базу. Не смешивать проект с moi-pary72/moi-pary.

## Следующий этап
1. Получить легальную копию Assets.zip из установленной игры Hytale (или проверенный набор игровых JSON).
2. Запустить: python scripts/import_game_assets.py Assets.zip --output data/hytale-recipes.json
3. Проверить количество и примеры рецептов, в частности Rudimentary Shortbow.
4. Добавить поддержку ResourceTypeId / ItemTag и нескольких рецептов одного предмета в калькулятор; затем подключить data/hytale-recipes.json через fetch.
5. Обновить UI, проверить на телефоне, только после этого выкладывать сайт.

## Важно
Публичный каталог hytale.source.gs заявляет 2080 рецептов для версии 0.6.4, но это НЕ проверенный источник полного JSON API. Не считать цифру импортированной базой.
Резервную копию и журнал проекта в Google Drive нужно обновить отдельно; этот файл в GitHub — дополнительный контрольный документ.
