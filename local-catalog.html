Твой каталог — прямо в браузере

Открой собственный JSON-файл каталога с телефона или компьютера. Файл читается только на этом устройстве, без отправки на сайт и без сохранения в облако.

Из архива Hytale Craft выбери файл research-data.json. Сначала распакуй ZIP в «Файлах» Android. На других устройствах можно выбрать совместимый файл формата canonical.items / canonical.recipes.

Каталог ещё не загружен.

Данные из стороннего источника могут относиться к старой версии игры. Наличие предмета и рецепта в текущем Hytale не подтверждено.

Неофициальный инструмент. Данные не загружаются на сервер, не публикуются и исчезают из страницы при обновлении или закрытии вкладки.
